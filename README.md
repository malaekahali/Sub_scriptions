# مشروع اشتراكات برامج التواصل الاجتماعي

## 📋 الوصف
موقع ويب لعرض وبيع اشتراكات برامج التواصل الاجتماعي بأسعار تنافسية.

## 🚀 البدء

### المتطلبات
- Visual Studio Code
- متصفح ويب حديث (Chrome, Firefox, Safari, Edge)
- إضافة Live Server لـ VS Code (اختيارية)

### التشغيل
1. افتح المشروع في Visual Studio Code
2. افتح ملف `index.html`
3. استخدم Live Server أو افتح الملف مباشرة في المتصفح

## 📁 هيكل المشروع
```
.
├── index.html          # الصفحة الرئيسية
├── payment.html        # صفحة الدفع
├── styles.css          # ملف التنسيقات
├── script.js           # ملف JavaScript
├── apple-pay.png       # صورة Apple Pay
├── visa.png            # صورة Visa
├── tabby.png           # صورة Tabby
└── tamara.png          # صورة Tamara
```

## 🎨 المميزات
- تصميم عصري وجذاب

- واجهة مستخدم سهلة
